## 📄 AI PDF Chatbot (RAG-Based)

An AI-powered document question-answering system that allows users to upload PDF files and interact with them through a conversational interface. The application uses a Retrieval-Augmented Generation (RAG) approach to extract relevant information from documents and generate accurate, context-aware responses.

### 🚀 Features

* 📤 Upload and process PDF documents
* ✂️ Automatic text chunking and embedding generation
* 🔍 Semantic search using vector similarity
* 💬 Chat interface for asking questions about documents
* ⚡ FastAPI backend with real-time responses
* 🎨 Modern UI built with React, TypeScript, and Tailwind CSS

### 🧠 Tech Stack

* **Frontend:** React (TypeScript), Tailwind CSS
* **Backend:** FastAPI (Python)
* **AI/ML:** OpenAI, LangChain
* **Vector Store:** FAISS (with option to use Pinecone)

### ⚙️ How It Works

1. User uploads a PDF
2. Text is extracted and split into chunks
3. Chunks are converted into embeddings
4. Stored in a vector database
5. User queries → relevant chunks retrieved → AI generates answer

### 📌 Use Cases

* Document analysis
* Research assistance
* Knowledge base chatbot
* AI-powered file interaction
